# LearnDockで研修を受講して完了を確認する

LearnDockでは必須研修と職種別認定を受講します。動画を最後まで再生しただけでは完了にならず、確認テストと受講記録を確認します。

## 割り当てを確認する

1. https://learn.devagent.example を開きます。
2. 「My Learning」で「必須」「職種別」「任意」を分けて表示します。
3. 期限が入社後5営業日以内の共通研修を先に確認します。
4. コースを開き、対象者、所要時間、完了条件、再受験条件を読みます。

## 受講する

1. 「Start course」を選びます。
2. 章ごとに教材を確認し、演習があれば合成データで実施します。
3. 途中で終了する場合は、章の状態が保存済みであることを確認します。
4. 最終の確認テストを受験します。
5. 不合格の場合は、失敗した領域と参照章を確認してから再受験します。

答えだけを共有したり、他人のアカウントで受講したりしません。教材と実運用が異なる場合は、正解を推測せずコースオーナーへ報告します。

## 完了確認

「My Learning」へ戻り、コースが「Completed」、完了日、テスト結果が表示されていることを確認します。PeopleDockのOnboardingタスクへ反映されるまで最大30分かかる場合があります。

30分後も反映されない場合は、LearnDockのコースID、完了時刻、状態をHelpPortの「Learning」へ登録します。再受講や別アカウントでの完了を試しません。

## 認定の更新

期限付きの製品認定は「Certifications」で有効期限を確認します。期限の30日前から更新コースを受講できます。顧客作業に必要な認定が期限切れになる場合は、マネージャーとDelivery Leadへ事前に共有します。
