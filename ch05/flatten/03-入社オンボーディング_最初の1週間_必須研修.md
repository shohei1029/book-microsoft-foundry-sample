# 最初の1週間の必須研修

必須研修はLearnDockに割り当てられます。期限は原則として入社後5営業日以内です。顧客対応や開発タスクより先に、法令と安全に関わる研修を完了します。

| 研修 | 内容 | 標準時間 |
| --- | --- | ---: |
| 行動規範 | ハラスメント防止、利益相反、贈収賄防止、相談窓口 | 60分 |
| 情報セキュリティ | 多要素認証、フィッシング、端末、インシデント報告 | 60分 |
| 個人情報と顧客データ | データ分類、利用目的、最小化、保持、削除 | 45分 |
| 安全なAI利用 | 承認済み環境、入力禁止情報、出力確認、記録 | 45分 |
| 製品基礎 | AgentWeave、Studio、Runtimeの関係 | 90分 |
| 顧客導入基礎 | Sales、Solution Engineering、FDEの役割 | 45分 |

## 研修の完了条件

動画を再生しただけでは完了になりません。各コースの確認テストに合格し、LearnDockが完了状態になっていることを確認します。不合格の場合は教材を見直して再受験できます。

## 職種別研修

共通研修の後、開発者とPMは安全な開発と製品分析、SalesとSolution Engineerは契約・提案・デモ、FDEは顧客環境と本番変更、バックオフィスは担当する法令・統制の研修を受けます。期限はマネージャーが30日ゴールへ設定します。

研修内容と実際のチーム運用が異なる場合は、自己判断で研修を無視せず、マネージャーと研修オーナーへ差分を報告します。古い教材であれば、HelpPortの「Learning」カテゴリから更新を依頼します。
