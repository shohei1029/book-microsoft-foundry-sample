# 用語集

| 用語 | 意味 |
| --- | --- |
| AgentWeave | エージェントをコードで開発するOSSフレームワーク。PythonとTypeScriptに対応する。 |
| Devagent Studio | AgentWeaveを基盤にしたノーコード/ローコード開発製品。コードとしてエクスポートできる。 |
| Devagent Runtime | 完成したエージェントを実行、監視、更新するクラウドベースのマネージド環境。 |
| Agent Project | エージェントのコード、設定、評価、依存関係をまとめた配布単位。 |
| Connector | 外部のデータや業務システムへ接続する再利用可能な部品。 |
| Evaluation Set | エージェントの品質を継続確認する入力例、期待、評価基準の組。 |
| Guardrail | 入出力やツール実行を制限、検査、記録する仕組み。 |
| Trace | 一回の実行に含まれるモデル呼び出し、ツール呼び出し、判断の記録。 |
| Sales | 商談、価格、契約、顧客関係を担当する営業職。 |
| Solution Engineer | 技術ディスカバリー、デモ、技術検証を担当するプリセールス職。略称はSEだが、文脈が不明な文書では正式名を書く。 |
| FDE | Forward Deployed Engineer。顧客環境に合わせた導入、実装、本番移行を担当する。 |
| PM | Product Manager。解く問題、優先順位、成功指標を定義する。プロジェクト管理だけを意味しない。 |
| DealDeck | 商談、顧客、契約、引き継ぎ条件を管理する社内CRM。 |
| LaunchPad | FDEの導入計画、成果物、リスク、顧客承認を管理するシステム。 |
| GateOne | SSO、多要素認証、アクセス申請を扱うシステム。 |
| Harbor | 社内規程、ニュース、ナレッジのポータル。 |
| HelpPort | IT、人事、総務、財務、法務への通常問い合わせ窓口。 |
| GuardLine | セキュリティインシデントの緊急報告窓口。 |
| Go live | エージェントを本番利用者へ提供開始すること。本番判定を通過した状態を指す。 |
| Adoption | 稼働だけでなく、対象業務で継続利用され成功指標が改善している状態。 |

社内略語は、初出で正式名を書きます。顧客との文書では、Devagent社内だけで通じる略語を使わないでください。
