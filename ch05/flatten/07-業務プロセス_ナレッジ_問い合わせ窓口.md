# 問い合わせ窓口

問い合わせ先を選ぶときは、緊急性と内容で判断します。通常の手続きはHelpPort、セキュリティ事故の疑いはGuardLineです。

| 内容 | 窓口 | 例 |
| --- | --- | --- |
| IT | HelpPort / IT | 端末故障、標準ソフト、通常のサインイン問題 |
| 人事 | HelpPort / People | 休暇制度、給与明細、所属情報、証明書 |
| 経費・出張 | HelpPort / Finance | SpendFlow、証憑、費目、出張規程 |
| 総務・調達 | HelpPort / Workplace | 入館、備品、購買、オフィス安全 |
| 契約・法務 | HelpPort / Legal | 契約レビュー、OSSライセンス、贈答・会食 |
| 製品の使い方 | チームの製品サポート | AgentWeave、Studio、Runtimeの通常質問 |
| 製品障害 | Relay `#runtime-status` | Runtime停止、広範なエラー、SLO違反 |
| セキュリティ | GuardLine | 誤送信、端末紛失、秘密漏えい、不審なログイン |
| 職場の緊急事態 | 総務緊急電話 | 火災、災害、生命・身体の危険 |

## HelpPortへ書くこと

完了したいこと、対象システム、期限、表示されたエラー、試したことを記載します。パスワード、APIキー、秘密鍵を貼り付けません。画面キャプチャには顧客情報や個人情報が含まれていないか確認します。

## 緊急時

セキュリティ事故は調査を完了してから報告する必要はありません。GuardLineへ事実と不明点を分けて連絡します。生命や身体の危険がある場合は、社内連絡より先に地域の緊急機関へ連絡します。

問い合わせの回答が繰り返し必要になる場合は、担当部門へHarbor文書または申請フォームの改善を提案します。
