# Devagent社オンボーディング情報源

このディレクトリは、Devagent社へ新卒または中途で入社する社員向けオンボーディングAgentの情報源です。

> **書籍用の架空データ**  
> Devagent社、製品、人物、社内制度、社内システム、URLはすべて架空です。実在する企業やサービスとは関係ありません。

## 情報の探し方

- 会社の全体像や部門間の関係: `01-会社と組織`
- AgentWeave、Devagent Studio、Devagent Runtime: `02-製品と顧客`
- 入社前から90日まで: `03-入社オンボーディング`
- アカウント、社内システム、セキュリティ: `04-社内システムとセキュリティ`
- 勤務、休暇、経費、報酬、評価: `05-働き方と人事制度`
- 職種ごとの最初の仕事: `06-職種別ガイド`
- 開発、顧客対応、ナレッジ管理: `07-業務プロセス`
- 社内・製品ツールの具体的な画面操作: `08-ツール操作ガイド`

規程と個別契約が異なる場合は、PeopleDockまたはHarborに掲載された最新版を優先します。判断に迷う場合はHelpPortで担当部門へ問い合わせてください。セキュリティ事故の疑いがある場合だけはHelpPortを待たず、GuardLineへ直ちに報告します。
