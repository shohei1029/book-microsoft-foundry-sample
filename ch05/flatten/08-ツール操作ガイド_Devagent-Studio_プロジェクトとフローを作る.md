# Devagent Studioでプロジェクトとフローを作る

Devagent Studioでは、ノードを接続してAgentWeave互換のエージェントを作成します。まずDevelopment環境で合成データを使い、評価後にレビューを依頼します。

![Devagent StudioのFlow Canvas。ノードパレット、キャンバス、プロパティ、テスト入力、実行ログを表示する。](assets_studio-flow-canvas.svg)

## 画面の見方

1. **ノードパレット**: Input、Prompt、Model、Tool、Condition、Human approval、Outputをキャンバスへ追加します。
2. **プロパティ**: 選択したノードの接続、入力、失敗時の動作を設定します。
3. **テスト入力**: 一件の入力でフローを実行し、実行ログとTraceを確認します。

## プロジェクトを作る

1. https://studio.devagent.example の「Projects」で「New Project」を選びます。
2. プロジェクト名を入力します。顧客名を含める必要がある場合は、承認済みの案件名を使います。
3. テンプレートを選びます。最初は `Blank agent` またはチーム承認済みテンプレートを使います。
4. オーナーチーム、データ分類、既定言語を設定します。
5. Development Workspaceを選び、「Create」を選びます。

## フローを構成する

1. Inputノードで入力名と型を定義します。例: `customer_message: string`。
2. PromptまたはModelノードへ、目的、使用可能な情報、出力形式、禁止事項を設定します。
3. Toolノードを追加し、管理者が承認したConnectorを選びます。
4. Toolの入力を前段ノードの値へマッピングします。
5. タイムアウト、結果なし、権限エラー時の動作を設定します。無限再試行にしません。
6. 高影響な操作にはHuman approvalノードを挿入します。
7. Outputノードで本文、引用、状態など利用者へ返す項目を定義します。

## 一件ずつテストする

1. 「テスト入力」に公開または合成データを入力します。
2. 「テスト」を選びます。
3. 実行ログで通過したノード、Tool入力、Tool結果、モデル応答を確認します。
4. Outputだけでなく、根拠、失敗時の分岐、個人情報のログ有無を確認します。
5. Trace IDを、修正メモまたはレビューへ記録します。

## 保存とレビュー前確認

Studioは入力途中を自動保存しますが、各ノードの「変更を適用」を押していない値は反映されません。画面上部が「保存済み」になったことを確認し、「Validate」で未接続ノード、未設定Connector、到達不能な分岐を解消します。

一件のテスト成功だけで公開せず、Evaluationを実行します。
