# Devagent Runtime

Devagent Runtimeは、AgentWeaveまたはDevagent Studioで作成したエージェントを実行するクラウドベースのマネージド環境です。

## 提供機能

- 不変のバージョン単位でのデプロイ
- 要求量に応じたオートスケール
- 環境ごとのシークレット参照と接続管理
- ログ、メトリクス、分散トレース、品質評価
- 監査ログとロールベースのアクセス制御
- カナリアリリース、段階的なトラフィック移行、ロールバック
- データ保持期間とリージョンの設定

## 環境

標準はDevelopment、Staging、Productionの3環境です。Developmentは開発者の反復、Stagingは本番相当の統合試験、Productionは承認済み利用者への提供に使います。顧客データをDevelopmentへコピーしてはいけません。必要な場合は匿名化したテストデータを作成します。

## 本番責任

すべての本番エージェントに、業務責任者、技術責任者、連絡先、評価セット、SLO、データ分類、ロールバック方法を設定します。Runtimeが基盤を運用していても、エージェントの応答品質や業務上の判断責任までDevagent社のプラットフォームチームへ移るわけではありません。

## 障害時

利用者影響を確認し、必要なら直前の正常バージョンへロールバックします。認証情報漏えいや顧客データの誤公開が疑われる場合は、通常の製品障害対応に加えてGuardLineへ報告します。詳細な原因が分かるまで報告を待ってはいけません。
