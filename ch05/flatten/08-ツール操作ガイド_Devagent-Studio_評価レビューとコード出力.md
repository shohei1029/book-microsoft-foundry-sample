# Devagent Studioの評価、レビュー、コード出力

フローを作成したら、固定したバージョンを評価し、レビュー後にRuntimeへ公開するかAgentWeaveコードとして出力します。

## 評価を作成する

1. プロジェクト上部の「評価」または左メニューの「Evaluations」を選びます。
2. 「New Evaluation」を選びます。
3. 評価セットを選びます。顧客データを使う場合は、目的とアクセス権を確認します。
4. 対象バージョンを選びます。編集中のDraftではなく、評価用に固定されたバージョンを選びます。
5. 正確性、根拠、安全性、Tool選択など必要な評価器を選びます。
6. 各指標と全体の合格基準を設定します。
7. 「Run」を選びます。

結果一覧で、ケース、結果、スコア、失敗理由、Traceを確認します。平均だけでなく、重大な失敗が一件でもないか確認します。失敗ケースを開き、入力、各ノードの出力、Tool、最終応答を比較します。

## レビューを依頼する

1. Flow Canvasへ戻り、「レビューを依頼」を選びます。
2. 変更目的、主な差分、評価結果、既知の制約を記載します。
3. 業務オーナー、技術レビュアー、データまたはセキュリティの必要レビュアーを追加します。
4. レビュー対象バージョンが評価したバージョンと同じことを確認します。
5. 「Request review」を選びます。

コメントへ対応してフローを変更すると新しいDraftになります。再度固定し、影響する評価を実行します。古い評価結果を新しい版の証拠に使いません。

## AgentWeaveコードへ出力する

1. 承認済みバージョンで、メニューの「Export」を選びます。
2. 言語をPythonまたはTypeScriptから選びます。
3. パッケージ名、AgentWeaveバージョン、出力形式を設定します。
4. 「互換性を確認」を選びます。Studio専用または出力先で利用できないConnectorがあれば解消します。
5. 「エクスポート」を選び、Agent ProjectをダウンロードまたはSourceNestの新規リポジトリへ送ります。
6. README、`agentweave.yaml`、ソース、評価セット、`.env.example`が含まれることを確認します。
7. SourceNestで依存関係検査、テスト、評価を実行します。

コードを変更した後、同じStudioプロジェクトへ自動で逆同期されるとは限りません。StudioとSourceNestのどちらを正とするかREADMEへ記載します。
