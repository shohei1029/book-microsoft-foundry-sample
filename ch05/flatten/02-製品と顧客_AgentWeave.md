# AgentWeave

AgentWeaveは、AIエージェントをコードで構築するOSSフレームワークです。Apache License 2.0で公開され、PythonとTypeScriptのSDKを提供します。

## 主な構成要素

- **Model Adapter**: 複数のモデルプロバイダーを共通インターフェースで扱う。
- **Tool**: API、データベース、業務操作を型付きの呼び出しとして公開する。
- **Flow**: 直列、分岐、並列、再試行、人による承認を組み合わせる。
- **Memory**: 会話状態と長期情報を用途別に分離する。
- **Evaluation**: テストデータと評価器を実行し、変更前後を比較する。
- **Tracing**: モデルとツールの実行を関連付け、遅延、失敗、コストを観測する。

## Agent Project

標準的なAgent Projectには、ソースコード、依存関係、環境別設定、評価セット、デプロイ定義を含めます。シークレットそのものは含めず、ローカルでは開発者用の安全な資格情報、Runtimeではシークレット参照を利用します。

## 互換性の考え方

マイナーバージョンでは既存APIの互換性を保ち、廃止予定のAPIには移行期間を設けます。破壊的変更はメジャーバージョンで行います。公開APIを変更するプルリクエストには、移行方法とリリースノートを含めます。
